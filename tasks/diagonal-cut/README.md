# 对角提取 / Diagonal cut

两份横向 1×2、三层蓝图：1 口 12 带输入，2 口各 12 带输出。右半平台上方输入，左半平台上方、下方输出。

- NE–SW：`CuCuCuCu` → 两路 `Cu--Cu--`。
- NW–SE：`CuCuCuCu` → 两路 `--Cu--Cu`。

用途是四个象限相同的常规形状。每条输入分给四个并联单元，每个单元整切、旋转两半、换半，再旋转其中一路，保留全部材料。输入和两个输出的内部带序有置换。每份 990 个建筑，包括 48 个整切机、48 个换半机，三层完全相同。

运行 `cargo run --release -p diagonal-cut` 生成两份 `.spz2bp`，并在隔离的原生 1.2.0-rc3 宿主中验收。检查原生导入与占地、12 个输入、24 个输出、120 秒预热后的 120 秒持续满载输出和全部输出形状。只有通过后才发布 `%TEMP%/shapez-lab/tasks/diagonal-cut/latest.json`。`*-harness.spz2bp` 为带外部星际传送带的测试夹具，导入工厂使用不带 harness 后缀的文件。
