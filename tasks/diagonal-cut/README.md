# 对角提取 / Diagonal cut

两份横向 1×2、三层蓝图：1 口 12 带输入，2 口各 12 带输出。左半平台上方输入，左半平台下方、右半平台下方输出，与用户提供的接口布局一致。

- NE–SW：`CuCuCuCu` → 两路 `Cu--Cu--`。
- NW–SE：`CuCuCuCu` → 两路 `--Cu--Cu`。

用途是四个象限相同的常规形状。每条输入分给四个并联单元，每个单元整切、旋转两半、换半，再旋转其中一路，保留全部材料。输入和两个输出的内部带序有置换。每份 993 个建筑，包括 48 个整切机、48 个换半机，三层完全相同。

运行 `cargo run --release -p diagonal-cut` 生成两份 `.spz2bp`，并在隔离的原生 1.2.0-rc3 宿主中验收。检查原生导入与占地、12 个输入、24 个输出、120 秒预热后的 120 秒持续满载输出和全部输出形状。只有通过后才发布 `%TEMP%/shapez-lab/tasks/diagonal-cut/latest.json`。`*-harness.spz2bp` 为带外部星际传送带的测试夹具，导入工厂使用不带 harness 后缀的文件。

已通过运行：`1794053519987-14548-0`；验收报告：`1794053520010-14548-1/report.json`。本次交付选择 1×2，没有产出 1×1 版本。

合并总线使用仅开放所需方向的双输入合并器，首项使用转弯带；原生连接图中的所有平台内连接口均已连接，只有测试夹具的三个外部星际接口开放。图库图标参照现有绿色形状与 ArrowDown 样式，上排完整绿色圆形和箭头，下排两个相同的绿色对角。两个图标通过原生导入/导出和版本 5 图库校验。


## 通用溢流蓝图朝向修正

`cargo run --release -p diagonal-cut --bin overflow -- <原蓝图路径>` 派生原图库蓝图，保留 1×2 三层布局和溢流结构，将 42 条直带替换为四分之一旋转器。常规输出端替换 18 条，另外两组并联处理段替换 24 条，避免修改溢流垃圾路径。原文件保留，新文件通过验收后写入同一图库目录。

以 `CgCbCgCb` 输入，24 条输出带只允许 `Cg--Cg--` 或 `--Cb--Cb`；原生模拟预热 120 秒，再采样 120 秒，检查每条带的形状和至少半带输出。原生导入、版本 5 图库检查均通过。验收报告：`1794057418011-8916-1/report.json`。
