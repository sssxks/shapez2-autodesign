# 12 带优先合流器

一个 `Foundation_1x1`，459 个建筑，三层各四路独立控制。

- 西侧：A，12 带优先输入。
- 北侧：B，12 带补流输入。
- 东侧：12 带输出。
- 每层西侧从北到南第 k 带、北侧从西到东第 k 带，对应东侧从北到南第 k 带。
- 南侧不连接。需要三层建筑、溢出分流器、读带器、过滤器和逻辑门。

每条 A 带分成主路和溢出旁路，在下游重新合流。旁路读带器经 IF 门将任意形状转换为布尔信号，再通过 NOT 门控制 B 过滤器。A 主路出现积压时关闭 B；A 供给不足时放行 B。过滤器未匹配出口不接收物料，不销毁 B。

这是带缓冲的反馈优先合流：切换时已进入下游的 B 会先排出。稳定供给下 A 满带则 B 停止，A 半带则 B 补另一半。每路独立判断，不因一条 A 满带而关闭整个 B 口。

单路电路改编自 [Rhaversen 的溢出检测设计](https://www.reddit.com/r/shapezio/comments/1l53i2c/input_priority_to_vortex/)。本任务重新布局四个单元，用带方向约束的 BFS 和 2–5 格发射器布线，再复制至三层；没有无线频道或外部控制信号。

## 生成与验收

```powershell
cargo run -p priority-merge
```

蓝图、布局、独立测试用蓝图和套件写入 `%TEMP%/shapez-lab/runs/<run-id>`；只有原生验收成功才发布 `tasks/priority-merge/latest.json`。测试蓝图额外附带三段太空带，交付蓝图仅包含一个平台。测量报告位于 suite 运行目录。

本机 Shapez 2 1.2.0-rc3 原生宿主使用 2 物品/秒基础带速、120 Hz 供料。每阶段预热 30 秒、测量 120 秒，12 路均满带：

- A/B 同时满供：每路 A=240、B=0。
- A 半供、B 满供：每路 A=120、B=120。
- 仅 A、仅 B、B 运行后恢复 A：每路正确来源 240。
- 同时将不同 A 路设为 0、1/3、2/3、满带：A 分别 0/80/160/240，B 分别 240/160/80/0。
- 堵住全部输出 15 秒，再恢复：稳定后每路 A=240、B=0。

24 条输入各用不同形状，错误输出身份直接使测试失败。验收检查各路总吞吐、优先输入份额、满供时 B 为零以及堵塞恢复。输入注入原生接收器的 InputLane，输出在原生发送器的 PathLane 末端计数，内部所有运输与信号由游戏执行。
