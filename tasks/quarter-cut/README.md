# 1×3 四象限切割器：12 带输入 → 48 带输出

成品使用 **横向 1×3 平台、三层建筑**。输入四个象限相同的普通单层形状，保留全部四份并统一到第一个象限：`CuCuCuCu → Cu------`。

[可导入蓝图：quarter-cut-1x3.spz2bp](templates/quarter-cut-1x3.spz2bp)。复制文件全部文本后在游戏中粘贴。需要解锁三层建筑及使用的切割、旋转、分流、合流、跳跃带和升降机。

## 接口

以成品原始朝向为准，每口都是三层 × 四带 = 12 带：

| 位置 | 用途 |
| --- | --- |
| 上边中间 | 输入 12 带完整形状 |
| 上边左端 | 输出 12 带四分之一形状 |
| 上边右端 | 输出 12 带四分之一形状 |
| 下边左端 | 输出 12 带四分之一形状 |
| 下边右端 | 输出 12 带四分之一形状 |

12 条输入应供应同一种目标形状，四个出口同时接走以保持满速。单元内合并四份切片，跨层走线不保持输入带与输出带的一一对应。多层形状、销钉、晶体不在本任务验收范围内。

## 布局与接口清理

每层两排切割单元，中间四格通道供料；两排单元末端侧向出料，为布线和外部接口留出空间。48 个单元各接收 0.5 个完整形状/秒，输出一条 2 个四分之一形状/秒的满带。成品共有 1,490 个建筑，其中完整切割器 144 台、旋转器 240 台、双输入合流器 144 台、分流器 36 台。

**没有三输入合流器，也没有闲置的合流器接口。** 原生验收逐台检查 144 台合流器：每台恰好两个输入，两个输入与输出均连接。跳跃带的禁用、阻塞状态也会使验收失败。

`src/layout.rs` 保存完整布局与分流连接，公共库 `crates/shapez-routing` 通过逐轮提高冲突格代价完成三层布线。除了建筑占格，求解器还保留跳跃带发射方向的配对范围，避免同一直线上多组跳跃带互相配错。等流量阶段允许交换目的地，输入链的四级关系保持不变。

1×3 原生平台的原点在中间区块。生成器以三个区块从左到右的全局坐标规划，再把建筑 X 坐标减去 20，写入中心区块位于 `(1,0)` 的蓝图岛屿。

## 运行

```powershell
cargo run -p quarter-cut                  # 打包已验收模板，并执行整机验收
cargo run --release -p quarter-cut -- --solve # 从布局重新求解、生成并验收
cargo run -p quarter-cut -- --cell         # 单元吞吐验收
cargo run -p quarter-cut -- --definitions  # 原生建筑定义
cargo run -p quarter-cut -- path/to/blueprint.spz2bp # 验收同接口约定的成品
```

构建产物保存在 `%TEMP%/shapez-lab/runs/<run-id>`；只有全部用例通过才更新 `%TEMP%/shapez-lab/tasks/quarter-cut/latest.json`。成品不包含测试用太空带、供料源或测量器。

## 原生验收

本机 Shapez 2 **1.2.0-rc3**：

- 原生蓝图导入、建筑占地、接口槽检查通过。
- 144 台双输入合流器全部连接，无闲置接口。
- 无禁用接收器或阻塞发射器。
- `CuCuCuCu` 输入：预热 180 秒，测量 120 秒，48 条输出每条 **240 个 `Cu------`**。
- `RrRrRrRr` 输入：48 条输出每条 **240 个 `Rr------`**。
- 全部出口堵塞 20 秒，解除并预热后再次测量，所有输出恢复满带。
- 图库图标、蓝图格式、无旧版本警告检查通过。

首次完整验收报告：`%TEMP%/shapez-lab/runs/1794056046166-21292-1/report.json`；逐带测量在同目录 `quarter-cut-measurements.json`。
